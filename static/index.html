燃气管线泄漏检测与隔离协调

评定依据、来源记录与处置动作按现场依据版本接起来：来源新增或替换即重新评定；依据变更后原评定、隔离、抢修、试压结论全部作废并留痕，事件回到待核验。

GET  /health
GET  /api/state
GET  /api/items/{id}
GET  /api/items/{id}/audit          # 审计哈希链 + chain_valid
GET  /api/items/{id}/basis          # 当前依据版本与版本历史
POST /api/items                     # 重复上报返回原记录(200, created=false)
POST /api/items/{id}/sources        # 重复来源幂等返回；新增/替换触发重新评定与结论作废
POST /api/items/{id}/source-batches/{batch_id}   # 离线批次连续页码，断点续传，同页只入库一次
POST /api/items/{id}/actions        # 处置动作带 expected_version + expected_basis_revision

隔离、抢修、试压、恢复必须携带 expected_basis_revision；依据版本落后或内容对不上返回 409 basis_conflict，响应 details.basis_diff 给出字段与来源证据差异。
